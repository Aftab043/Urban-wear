# Urban Wear

A modern and responsive **fashion e-commerce website** built using HTML and CSS.

## Live Website

[Visit Urban Wear](https://urbanweard.netlify.app/)

## Features

* Responsive navigation bar
* Modern hero section
* Men's, Women's, Shoes and Accessories categories
* Product cards with price and discount
* Add to Cart buttons
* Why Choose Urban Wear section
* Newsletter subscription section
* Responsive footer
* Clean and modern user interface

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Responsive Design
